# SafeReport โรงเรียน

เว็บต้นแบบสำหรับ "แจ้งเหตุภายในโรงเรียนอย่างปลอดภัย"
- รับรายละเอียดเหตุการณ์และรูปภาพ
- รองรับการแจ้งแบบไม่ระบุตัวตน
- มีหน้า Admin สำหรับครู/ผู้ดูแล
- ไม่แสดงรายงานต่อสาธารณะ
- เตรียม schema สำหรับ Supabase

## สำคัญ
เวอร์ชันที่เปิดไฟล์ `index.html` ได้ทันทีใช้ LocalStorage เพื่อสาธิตเท่านั้น
หากนำขึ้นอินเทอร์เน็ตจริง ควรเชื่อม Supabase + Storage + Supabase Auth และห้ามฝังรหัสผ่าน Admin ไว้ใน JavaScript

## ทำให้เข้า Google/มือถือ
1. สมัคร Vercel (หรือ Netlify)
2. สร้างโปรเจกต์ Supabase
3. รัน `schema.sql`
4. สร้าง Storage bucket สำหรับรูป
5. เชื่อม Supabase Auth สำหรับครู/ผู้ดูแล
6. แก้โค้ดให้ส่งข้อมูลไป Supabase
7. อัปโหลดโปรเจกต์ขึ้น Vercel แล้วจะได้ URL `https://....vercel.app`
8. เปิด URL จาก Chrome ในมือถือได้ทันที และสามารถเพิ่มเป็นไอคอนหน้า Home ได้

## ความเป็นส่วนตัว
ระบบนี้ควรจำกัดสิทธิ์หลังบ้านอย่างเคร่งครัด, เก็บข้อมูลเท่าที่จำเป็น, มีการตรวจสอบข้อเท็จจริง และไม่ควรนำชื่อหรือรูปของผู้ถูกรายงานไปเผยแพร่สาธารณะ
